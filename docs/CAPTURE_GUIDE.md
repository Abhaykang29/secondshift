# Capture guide (for Person A)

## Walkthrough (2-3 minutes)
- Room order: entry -> living -> kitchen -> hallway -> bedroom -> bathroom -> stairs.
- Lights on. Slow pan. Include floors and stair edges.
- Narrate as you go - tell us anything we should know (e.g. "Mom gets up twice a night").
- Consent first: the resident knows and agrees. Never film anyone in a bathroom or undressed.
- Ray-Ban Meta glasses: export the MP4 from the Meta AI app and upload it as a Ray-Ban import.

## Routine clip (30 seconds, optional)
- Prop the phone STILL (moving cameras break path geometry). Film the person walking their real daily path once (e.g. bed -> bathroom).
- One take, normal pace, no acting.

## Measurements (optional)
- Free-form: label + number + unit (e.g. "toilet seat height, 38, cm").

## Staging for eval spaces
- Some hazards deliberately staged (rug at top of stairs, cord across hallway, cleaning bottles low, unanchored bookcase, toys in crib); some spaces left clean as hard negatives.
